# OASIS INFOBYTE – Java Development Internship

This repository contains the Java development projects completed as part of my **Oasis Infobyte Internship**.

It brings together two independent projects developed to strengthen my programming skills, problem-solving abilities, application design, and understanding of software development workflows.

## Projects

### 1. Online Reservation System

**Directory:** `JavaDevelopment-Task1-OnlineReservationSystem/`

A graphical reservation application designed to manage transport reservations.

**Main features:**
- User authentication.
- Transport reservation management.
- Ticket booking.
- Reservation cancellation using a PNR number.
- Database integration.
- Input validation and reservation management.

**Technologies:** Java, Swing, JDBC, relational database.

[View project documentation](JavaDevelopment-Task1-OnlineReservationSystem/README.md)

### 2. ATM Interface

**Directory:** `JavaDevelopment-Task2-ATMInterface/`

A Java application that simulates basic ATM operations and banking transactions.

**Main features:**
- User authentication.
- Bank account management.
- Balance consultation.
- Cash deposits and withdrawals.
- Money transfers between accounts.
- Transaction history.
- Transaction validation and error handling.

**Technologies:** Java.

[View project documentation](JavaDevelopment-Task2-ATMInterface/README.md)
